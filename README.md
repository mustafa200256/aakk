# Mustafa Hussein — Teaser Experience

- index.html : التجربة كاملة (HTML/CSS/JS بدون أي مكتبات خارجية، 3D مكتوب يدوياً على Canvas)
- audio/bella-ciao.mp3 : ملف الأغنية الأصلي كما وصل، بدون أي تعديل

## التشغيل
افتح عبر أي سيرفر ثابت (مثلاً: npx serve . أو python3 -m http.server)، أو انسخ المحتوى داخل مجلد public في مشروعك.

## الدمج في مشروع موجود
- ضع audio/bella-ciao.mp3 في public/audio/ وعدّل مسار <audio src> إذا لزم.
- الصفحة لا تستخدم أي API ولا تقرأ أو تعدّل أي مفاتيح.

## المشهد الأخير (الفيديو)
- video/original.mp4 : الفيديو الأصلي كما وصل (محفوظ بدون تعديل)
- video/final.mp4 + video/final.webm : نسخ مضغوطة للويب (720p) والمتصفح يختار المناسب
- يبدأ المشهد تلقائياً بعد حوالي 7 ثواني من الوصول لآخر جملة "هذه البداية."
